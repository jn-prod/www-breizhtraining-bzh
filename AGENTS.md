# www.breizhtraining.bzh

Site de copains, gratuit, maintenu par Nicolas. HTML, CSS et JS publiés tels quels par GitHub Pages
depuis `main` : aucune dépendance, aucun build, aucun workflow. Ne pas en rajouter.

- Stages : lus dans Google Sheets par le navigateur (`main.js`), clé limitée au domaine.
- Images : à recompresser avant commit (2000 px de large au plus, JPEG 85 %).
- Mentions légales : `mentions-legales.html`. Tout nouvel appel à un tiers y est déclaré.
