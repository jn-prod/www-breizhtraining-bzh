# www.breizhtraining.bzh

Site personnel de Gaël Le Bellec, maintenu gratuitement par Nicolas. HTML, CSS et JS publiés tels quels
par GitHub Pages depuis `main` : aucune dépendance, aucun build, aucun workflow. Ne pas en rajouter.

- Stages : lus par le navigateur dans l'export CSV public de la feuille Google (`main.js`), sans clé.
  La feuille doit rester partagée en lecture. Attention : l'export déduit le type de chaque colonne, un
  texte isolé dans une colonne de nombres ou de dates peut sortir vide.
- Images : à recompresser avant commit (2000 px de large au plus, JPEG 85 %).
